\# Retail Sales Performance Analysis using Excel



\## Project Overview

This project focuses on analyzing retail sales data using Microsoft Excel. The goal is to understand sales performance across different cities, products, and salespeople using formulas, Pivot Tables, and charts.



\## Tools and Technologies

\- Microsoft Excel

\- Excel formulas and functions

\- Pivot Tables

\- Data cleaning and formatting

\- Charts and Dashboard



\## Dataset

The dataset contains 25 retail orders with the following information:

\- Order ID

\- Order Date

\- Customer

\- City

\- Region

\- Product

\- Category

\- Quantity

\- Unit Price

\- Salesperson

\- Payment Method

\- Order Status

\- Revenue



\## Work Performed

1\. Organized and formatted the raw retail sales dataset.

2\. Calculated revenue using Quantity × Unit Price.

3\. Used Excel functions including SUM, AVERAGE, MAX, MIN, COUNTIF, and COUNTA.

4\. Created Pivot Tables for city-wise, product-wise, and salesperson-wise revenue analysis.

5\. Built a sales performance dashboard with KPI metrics and three charts.



\## Key Business Insights

\- Total Revenue: ₹7,47,500

\- Total Orders: 25

\- Average Order Revenue: ₹29,900
